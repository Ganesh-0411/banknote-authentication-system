Deep Learning-Based Banknote Authentication System

Advanced image screening powered by a CNN Convolutional Autoencoder and one-class anomaly detection. Learns the visual characteristics of genuine Indian currency (₹10, ₹20, ₹50, ₹100, ₹200, ₹500, ₹2000) and flags micro-pattern irregularities through Mean Squared Error (MSE) reconstruction analysis.

Pipeline Architecture

2. DL4J CNN Autoencoder
3 Conv/Downsample blocks + 3 UpSample/Conv blocks with Sigmoid
3. MSE & Anomaly Detection
Calculates reconstruction loss against validation-calibrated threshold
